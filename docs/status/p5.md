# P5 — Month view: status

Branch `ph/p5-month`. State: built, `scripts/gate.sh fast` green. Not run in a simulator.

## Done (`App/Habitat/Features/Month/`)

- `MonthModel.swift`: pure value types. `DonutGeometry.arcs(count:)` (segment maths, one segment =
  full ring), `MonthCellBuilder` (grid padded to 6 rows, per-day segments, filter), `MonthDayCell`,
  `MonthSymbols` (localised month/weekday names, no `Date` maths).
- `DonutView.swift`: Canvas-free `Shape` arcs; done = full colour, thick; not done = dim, thin.
- `MonthView.swift`: header (previous / title / next, +-120 months), filter chips, weekday header,
  42-cell grid, day sheet, reload on appear / month change / toggle.
- `DaySheet.swift`: the day's habits with toggles (`CompletionRepository.toggle`), disabled on future days.

## Identifiers

`month.screen`, `month.title`, `month.previous`, `month.next`, `month.day.<yyyy-MM-dd>` (value
`done/active`, e.g. `3/5`), `month.filter.all`, `month.filter.<habitUUID>` (trait selected),
`month.daySheet`, `month.daySheet.toggle.<habitUUID>` (value `done` / `not done`),
`month.daySheet.close` (button label "Close"). The donut is not exposed separately (`month.donut.*` not used).

## Defaults taken

1. Cell label "Monday 2 November, 3 of 5 habits done" (", today" added; ", no habits" when none), value `3/5`.
2. A day counts habits by lifetime (created..archived inclusive), so archived habits still show in
   past days; chips list non-archived habits only. An archived habit's filter falls back to All.
3. Tapping a future day (or a day outside the month) opens the sheet; toggles are disabled for
   future days. The sheet lists only habits active that day (no disabled out-of-lifetime rows).
4. Filter is single-select; a habit not active on a day gives an empty faint ring ("0/0").
5. Not-done signal: dim and thinner segment (plus the accessibility value). Today: accent border,
   tinted background and heavy number. Days outside the month at 40 % opacity.
6. At accessibility Dynamic Type sizes the weekday header uses one letter and day numbers
   use `caption2`; the grid stays 7 columns.
7. Navigation limited to +-10 years from today's month. Errors from repositories show an alert.
8. Month data reloads on appear, so edits made in other tabs show up when returning.
9. Out-of-month days dim only the donut (day number stays primary, light weight); chip and sheet helper text use primary colour; not-done segments at 50 % opacity; a filter whose habit is gone is reset to All; load and save errors have separate alert titles.
