# P3 — Habit list + editor: status

Branch `ph/p3-habits`. Code only under `App/Habitat/Features/Habits/`.

## Done

- `HabitsView`: list of active habits (colour dot, name, goal text, flame + streak), empty state,
  add (+) opening the editor sheet, tap a row to edit, swipe to archive with a confirmation
  dialog, `EditButton` + `onMove` reorder (`HabitRepository.reorder`), "Archived" section behind a
  "Show archived" toggle with swipe to unarchive, error alert (`localizedDescription`).
- `HabitEditorView`: name (trimmed, required, inline message), colour swatches from
  `Theme.habitPalette`, goal picker (Every day / Times a week) with stepper over `Goal.weeklyRange`.
- View models (`@MainActor @Observable`): `HabitsViewModel`, `HabitEditorModel`; text in `HabitFormat`.
- Streak per row = `CompletionRepository.streak(habitID:)` as of `services.today`.
- VoiceOver: each row is one element labelled "name, goal, streak[, Archived]" with a hint.

## Accessibility identifiers

`habits.screen`, `habits.list`, `habits.add`, `habits.edit` (EditButton), `habits.row.<id>`,
`habits.archive.<id>` (swipe button), `habits.archiveConfirm`, `habits.showArchived`,
`habits.unarchive.<id>`, `habits.empty`, `habits.empty.add`, `habits.editor`,
`habits.editor.name`, `habits.editor.error`, `habits.editor.color.<RRGGBB>`,
`habits.editor.goalKind`, `habits.editor.weeklyCount`, `habits.editor.cancel`,
`habits.editor.save`. (Editor ids use the `habits.editor.*` form requested, not `habitEditor.*`;
add button is `habits.add`, not `habits.addButton`.)

Notes for QA:
- `habits.archiveConfirm` is on a confirmationDialog button; find it by label "Archive <name>"
  among the sheet/alert buttons (`app.sheets` / `app.alerts`), not by identifier.
- The shell UI tests still look for `habits.placeholder`; update them to `habits.screen`.
- Row streak caption is "3 d" (daily) or "3 wk" (weekly); the row's VoiceOver label has the full text.
- Archived rows do not open the editor.

## Defaults taken

1. Weekly streaks are counted in weeks ("3 week streak"), daily in days; zero shows "No streak"
   (flame greyed, number 0).
2. Goal text: "Every day", "Once a week", "N times a week".
3. Archive asks for confirmation (dialog); there is no undo. Archived rows are shown only when
   "Show archived" is on; they open no editor, and only offer Unarchive.
4. Save stays enabled; an empty/blank name shows the validation message on Save.
5. Switching the goal back to "Times a week" starts at 3 for a new habit.
6. EditButton appears only with 2 or more active habits.
7. New habit colour defaults to `Theme.defaultHabitColorHex`.
