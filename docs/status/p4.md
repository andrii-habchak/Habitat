# P4 - Week view: status

Branch `ph/p4-week`. State: implemented, `scripts/gate.sh fast` green. Not run in a simulator
(QA does that). Code in `App/Habitat/Features/Week/` only.

## Done (R-WEEK, R-STREAK on the week view)

- `WeekView.swift`: `NavigationStack` + paged `TabView` over weeks (offset 0 = week of
  `services.today`, back to 104 weeks). Title = week range. Toolbar `week.previous` / `week.next`.
  Per page: weekday letters + day numbers (today highlighted), one card per habit (colour dot,
  name, `c/N` + status icon and text for weekly goals, streak), 7 toggle cells. Empty state when
  the week has no habits. At accessibility Dynamic Type sizes each card lists the 7 days
  vertically instead of a 7-column row.
- `WeekViewModel.swift`: `@MainActor @Observable` model (`pageRows` / `reload()` for the visible week and neighbours, `toggle`, paging) and the
  pure `HabitWeekRow.make` builder. Toggle goes through `CompletionRepository.toggle`; status via
  `WeeklyProgress` / `WeeklyStatus.evaluate`; streak via `Habit.streak` as of today.
- `WeekFormat.swift`: English day/week text from `DayKey`.

## Identifiers

`week.screen` (on the paged TabView), `week.previous`, `week.next`, `week.emptyState.<monday>`,
`week.header.<habitId>.<monday>` (name), `week.cell.<habitId>.<yyyy-MM-dd>` (value `done` /
`not done`; disabled for future and out-of-lifetime days), `week.progress.<habitId>.<monday>`
(weekly goals only; value `met` / `failed` / `in progress`; label "Goal N days a week, c done"),
`week.streak.<habitId>.<monday>` (value = number). `<monday>` is the `yyyy-MM-dd` of the page's
week start. Only the visible week and its two neighbours are in the hierarchy.
Cell label "Read, Monday 2 November" + value + toggle trait. `week.placeholder` is gone.

## Defaults taken

1. Layout is a card per habit (header line, then 7 cells aligned under one shared weekday
   header) rather than one literal table, so names have room at any text size.
2. Daily habits show no `c/N` or status (only weekly goals, PLAN R-WEEK); `week.progress` does
   not exist for them. Streak is shown for every habit: "N days" (daily) / "N weeks" (weekly).
3. Streak is always as of today, also when browsing past weeks.
4. A week lists habits whose lifetime touches it (created on/before Sunday, not archived before
   Monday), archived ones included; archived habits drop out only for later weeks.
5. Cannot page forward past the current week; back limit 104 weeks.
6. Status icons: met = checkmark.circle.fill, failed = xmark.circle.fill, in progress = clock;
   texts are not shown, the `c/N` count plus icon carries it; spoken value has the word.
7. Texts are English, not localised. Toggle errors are stored in `errorMessage` but not shown
   (cells that would error are disabled).
8. The tab refreshes data on appear, so habits added elsewhere appear after switching tabs.
