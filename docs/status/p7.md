# P7 (reduced): Settings, export/import UI

Branch `ph/p7-settings`. `scripts/gate.sh fast` green. Not run in a simulator (QA does).

## Built

- `Features/Settings/SettingsView.swift`, `SettingsModel.swift` (main-actor `@Observable`).
- Data: Export (temp file `habitat-export-<yyyy-MM-dd>.json`, day from `services.today`, system
  share sheet; the temp file is deleted when the sheet is dismissed). Import (`.fileImporter` for
  JSON, security-scoped read, Merge / Replace / Cancel dialog, summary or readable error, then
  `reminderSync?.replan()`).
- About: app name, version (build) from the bundle, "Data stays on this device." Values use
  primary text colour.
- Errors use `ErrorText` (`Theme.Status.failed` plus icon) and "Nothing was changed."
- Row polish: Habits row (name/goal vs streak) and Reminders row (time vs days) stack vertically
  at accessibility Dynamic Type sizes.

## Accessibility ids

`settings.screen`, `settings.export`, `settings.exportError`, `settings.import`,
`settings.import.merge`, `settings.import.replace`, `settings.importResult`,
`settings.importError`. `settings.placeholder` is gone. The confirmation dialog buttons are found
by label: "Merge", "Replace", "Cancel".

## Defaults taken

1. Export builds the file on tap, then opens the share sheet.
2. The dialog has Cancel, which drops the picked file.
3. The summary shows added counts, and removed counts only when something was removed.
4. A file read failure is shown as an import error with the same "Nothing was changed." note.
