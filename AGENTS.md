# Habitat — agent guide

Habit tracker for iPhone. SwiftUI, Swift 6, SwiftData, iOS 17+. Single user, data stays on the
device. Free distribution: no paid Apple Developer account (ad-hoc / personal-team signing).
This file is the entry point for any agent (or human) picking the work up.

## Read order

0. `docs/NEXT.md` — hand-off prompt for a new orchestrator session (`scripts/kickoff.sh`).
1. `docs/STATUS.md` — where the work stands, what is in flight, what is next.
2. `docs/PLAN.md` — product rules, phases, pipeline, test strategy, run clock.
3. `docs/DECISIONS.md` — settled decisions. Do not re-open them without the owner.
4. `docs/status/<phase>.md` — progress notes of the phase you are continuing.

## Roles

- **Orchestrator** (lead session): controls only. Starts agents, reads their reports, decides,
  merges lanes, pushes `integration`, keeps `docs/STATUS.md` / `docs/NEXT.md` / `docs/DECISIONS.md`
  current. Writes no feature code, tests or UI.
- **Implementer** (one phase): own worktree + branch `ph/<id>-<slug>`. Writes the code and its
  unit tests, runs the fast gate, commits on its branch. Fixes review findings.
- **Reviewer**: fresh agent, read-only. Reviews the diff against the phase's acceptance criteria,
  re-runs the gate itself, returns findings as `must-fix` / `should-fix`.
- **QA**: fresh agent. Writes the XCUITests for the phase from the acceptance criteria (not from
  the implementation), runs them in the simulator, takes screenshots, reports bugs.

## Working rules

- **Docs are the shared memory.** Whoever finishes or pauses work updates the status notes in the
  same commit. A fresh agent must be able to resume from the docs alone.
- Commit after each finished step with build + tests green. Message: short imperative title,
  bullet body, a `Verified:` line.
- **No AI attribution anywhere**: no co-author trailers, no assistant/tool names in commits,
  branches, PRs, README or docs (owner rule).
- Git identity is per-repo (`andrii-habchak` / personal email) and the remote uses the SSH host
  alias `github-vigil`. Never switch to the global/work identity, and do not use the `gh` CLI
  for this repo (it is logged in with a different account).
- Everything stays inside the repo: build output under `build.noindex/` (git-ignored), scratch in
  the session scratch folder. Do not write into `~/Library` or edit other apps' configuration.
- Do not invent requirements. Anything unclear: take a proposed default and log it in
  `docs/STATUS.md` "Decisions for owner" (the owner cannot answer during a run, PLAN §11).
- Branches: lanes use `ph/<id>-<slug>`; the orchestrator uses `integration` and pushes it. Never
  commit on or push `main` (the owner's guard refuses it); the owner updates `main`.
- Run clock: `scripts/deadline.sh`. When it says FREEZE or STOP, follow `docs/PLAN.md` §10.

## Build facts (this Mac)

- Xcode 27.2, iOS 27.x simulators only. `xcode-select` points at Xcode.
- The Xcode project is generated by **xcodegen** from `project.yml`; the `.xcodeproj` is
  git-ignored and regenerated by the gate.
- QA simulator: `Habitat-QA` (UDID in `.run/sim-udid`, created by `scripts/kickoff.sh`).
  Only QA agents run UI tests in it, one at a time. Implementers never boot it.
- Gate (created in phase 0): `scripts/gate.sh fast` (lint, `swift test` in `HabitatKit/`, app
  build for the simulator, warnings as errors) and `scripts/gate.sh full` (+ XCUITests).
